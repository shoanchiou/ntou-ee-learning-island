# 電機學程島 EE Island

以國立臺灣海洋大學電機系課程資料為基礎的互動式學習導覽，參考 HEART 政策島的島嶼探索概念，從大一開始逐步認識課程，探索六個領域並選擇三門核心，最後整理個人學習航線。

## 開始使用

這是靜態網站。開啟 `index.html` 即可使用；插圖、互動程式與三份原始文件皆已包含在其中。也可透過靜態網站服務部署。

## 課程資料

- 關聯圖 A 用於年級與學期的課程位置；關聯圖 B 用於六選三核心科目。兩圖未標示適用入學年度，原圖 A 的核心規則為六選四。
- 輔系科目表是輔系資料；原表列至少 25 學分，但八筆必修各 3 學分，合計 24 學分。
- 領域與課程的關聯為探索導覽，最終實際修課、學分及畢業資格應以適用入學年度之系辦規定為準。加深加廣的額外科目在此版本中暫時略過。

系上的[課程規劃](https://ee.ntou.edu.tw/p/412-1062-7484.php?Lang=zh-tw)與[修業規定](https://ee.ntou.edu.tw/p/412-1062-7483.php?Lang=zh-tw)可供進一步查詢。系主任為虛構導覽角色，校園島嶼插圖為本專案原創。
